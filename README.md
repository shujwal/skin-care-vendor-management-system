# 📦 Python Inventory Management System

A menu-driven terminal application built in Python to help small businesses manage their inventory efficiently. Handles stock tracking, sales, purchases, and invoice generation — all from the command line.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📥 Add Stock | Add new products or restock existing items |
| 🛒 Process Sales | Record sales and automatically update stock levels |
| 📦 Manage Purchases | Log purchase orders from suppliers |
| 🧾 Generate Invoices | Create invoices for sales transactions |
| 📊 View Inventory | Display current stock with quantities and details |

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Interface:** Terminal / Command Line
- **Paradigm:** Procedural Programming
  
---

## 📁 Project Structure

```
inventory-management-system/
│
├── main.py          # Entry point — runs the menu loop
├── inventory.py     # Stock management logic
├── sales.py         # Sales processing
├── purchase.py      # Purchase order handling
└── invoice.py       # Invoice generation
```
